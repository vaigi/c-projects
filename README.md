# C Programming Projects Portfolio

Данный репозиторий является единым пространством для хранения и демонстрации низкоуровневых системных и алгоритмических проектов, разработанных на языке программирования Си. 

Основная цель репозитория — демонстрация навыков построения архитектуры на чистом Си, строгого управления динамической памятью, написания Makefile-скриптов автоматизации и стопроцентного покрытия функционала кроссплатформенными юнит-тестами.

## Навигация по проектам

В репозитории реализована модульная структура. Каждый проект изолирован в своей директории со своим собственным сборочным файлом и подробной технической документацией:

### 1. [matrix](./s21_matrix/)
* **Описание:** Собственная полнофункциональная статическая библиотека на Си для работы с численными матрицами и базовыми алгоритмами линейной алгебры.
* **Ключевой стек:** C11, GCC, Makefile, Check.h, gcov, lcov.
* **Статус:** Завершен, протестирован на утечки памяти (Valgrind/leaks), покрыт тестами более чем на 80%.

## Общие требования к коду в репозитории

Все проекты, размещенные в данном репозитории, соответствуют строгим внутренним стандартам качества:
1. **Стандарты кодирования:** Исходный код всех модулей написан исключительно в рамках стандартов C11 и POSIX.1-2017. Устаревшие и выведенные из употребления библиотечные функции (legacy/obsolete) полностью исключены.
2. **Стиль кода:** Все исходные файлы (`.c`, `.h`) во всех проектах отформатированы с помощью автоматических линтеров строго по спецификации Google Style Guide.
3. **Безопасность памяти:** Каждое выделение динамической памяти строго контролируется. Проекты проходят обязательную валидацию утилитами Valgrind или leaks на предмет отсутствия утечек и работы с неинициализированной памятью.
4. **Тестирование:** Логика функций проверяется модульными тестами с обязательной сборкой интерактивных отчетов покрытия кода.
