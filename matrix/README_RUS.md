# matrix: библиотека на языке С для работы с матрицами

Реализация библиотеки на языке С (стандарт C11) для работы с числовыми матрицами. Проект включает в себя полный цикл операций: от безопасного выделения динамической памяти до вычисления обратных матриц и построения строгой кроссплатформенной модели тестирования.

## Технологический стек и спецификация
* **Язык разработки:** C (стандарт C11).
* **Компилятор:** GCC.
* **Стиль кода:** Google Style Guide (clang-format).
* **Сборочная утилита:** Makefile (с поддержкой кроссплатформенности macOS / Linux).
* **Тестирование:** Юнит-тестирование на базе фреймворка Check.h (с поддержкой subunit на Linux).
* **Анализ покрытия:** gcov, lcov (с включенным анализом покрытия ветвлений lcov_branch_coverage=1).

## Структура матрицы в памяти
Матрица реализована в виде структуры с двумерным динамическим массивом (массив указателей на строки типа double):

```c
typedef struct matrix_struct {
    double** matrix;
    int rows;
    int columns;
} matrix_t;
```

## Справочник функций и кодов возврата

Все основные функции (кроме сравнения матриц) возвращают статус выполнения в виде целочисленного кода:
* **0 (OK)** — Операция выполнена успешно.
* **1 (INCORRECT_MATRIX)** — Некорректная структура матрицы (указатель равен NULL, динамическая память не выделена, размеры меньше или равны 0).
* **2 (CALC_ERROR)** — Ошибка математических вычислений (несовпадающие размеры матриц при арифметике, несовпадение столбцов и строк при умножении, вычисление детерминанта для неквадратной матрицы).

### 1. Управление памятью
* `int s21_create_matrix(int rows, int columns, matrix_t *result);` — Выделение памяти под строки и столбцы.
* `void s21_remove_matrix(matrix_t *A);` — Безопасное каскадное освобождение памяти (free) и обнуление всех полей структуры для предотвращения утечек.

### 2. Сравнение матриц
* `int s21_eq_matrix(matrix_t *A, matrix_t *B);` — Поэлементное сравнение. 
  * Возвращает: SUCCESS (1) — матрицы равны, FAILURE (0) — матрицы не равны.
  * Точность сравнения вещественных чисел (double) реализована через fabs вплоть до 6 знаков после запятой включительно (1e-6).

### 3. Арифметика и линейные преобразования
* `int s21_sum_matrix(matrix_t *A, matrix_t *B, matrix_t *result);` — Сложение матриц одинаковой размерности.
* `int s21_sub_matrix(matrix_t *A, matrix_t *B, matrix_t *result);` — Вычитание матриц одинаковой размерности.
* `int s21_mult_number(matrix_t *A, double number, matrix_t *result);` — Скалярное умножение элементов матрицы на число.
* `int s21_mult_matrix(matrix_t *A, matrix_t *B, matrix_t *result);` — Матричное умножение. Валидирует условие равенства количества столбцов первой матрицы количеству строк второй матрицы.

### 4. Алгоритмы линейной алгебры
* `int s21_transpose(matrix_t *A, matrix_t *result);` — Транспонирование матрицы (замена строк столбцами).
* `int s21_determinant(matrix_t *A, double *result);` — Рекурсивное вычисление определителя (детерминанта) для квадратных матриц методом разложения по строке.
* `int s21_calc_complements(matrix_t *A, matrix_t *result);` — Вычисление матрицы алгебраических дополнений через знак миноров и рекурсивный расчет детерминанта миноров.
* `int s21_inverse_matrix(matrix_t *A, matrix_t *result);` — Поиск обратной матрицы. Возвращает CALC_ERROR (2), если детерминант равен 0.

### Внутренняя декомпозиция (Вспомогательные функции)
Для чистоты архитектуры и переиспользования кода внутри библиотеки реализованы приватные функции:
* `s21_check_matrix` — Комплексная валидация структуры.
* `s21_check_matrix_size` — Валидация совпадения размеров матриц.
* `s21_get_minor_matrix` — Формирование усеченной матрицы (минора) путем вычеркивания строки и столбца.
* `s21_calculate_determinant` — Внутренний рекурсивный движок расчета детерминанта для матриц размерностью N на N.

## Инструкция по автоматизации и сборке

Управление компиляцией, тестированием и линтингом автоматизировано через Makefile.

* `make all` / `make` — Сборка проекта (цель по умолчанию, компилирует статическую библиотеку).
* `make s21_matrix.a` — Компиляция исходных файлов проекта и упаковка в статический архив с помощью ar rcs.
* `make test` — Сборка и автоматический запуск модульных тестов из директории tests с помощью утилиты Check.
* `make gcov_report` — Анализ тестового покрытия. Пересобирает проект с флагами компиляции --coverage, выполняет тесты, собирает статистику lcov с фильтрацией самих тестов (исключает модули тестирования), включает отображение покрытия ветвлений и генерирует интерактивный HTML-отчет в папке report. Автоматически открывает отчет в браузере с помощью xdg-open или open.
* `make leaks` — Запуск теста под Mac-утилитой leaks для проверки динамической памяти на наличие утечек при выходе из программы.
* `make clang` — Скопировать конфигурационный файл и автоматически отформатировать все файлы исходного кода во всех директориях строго по стандарту Google Style.
* `make clean` — Полная очистка сборочной директории от объектных файлов, статических библиотек, исполняемых файлов тестов, временных файлов и сгенерированных HTML-отчетов.
