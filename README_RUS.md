# C Programming Projects Portfolio

Репозиторий для хранения проектов на языке Си. 

## Директория проекта

```text
.
├── s21_matrix/         # Библиотека для работы с матрицами (C11, Check.h)
│   ├── tests/          # Модульные тесты
│   ├── Makefile        # Скрипт сборки и тестирования
│   ├── *.c, *.h        # Исходный код и заголовочные файлы
│   ├── README_RUS.md   # Документация проекта на русском языке
│   └── README.md       # Документация проекта на английском языке
├── README_RUS.md 
└── README.md
```

## Список проектов

* **[matrix](./matrix/)** — Библиотека для работы с матрицами. Реализованы базовые арифметические операции, транспонирование, поиск определителя и обратной матрицы. Код написан по Google Style, полностью проверен на утечки памяти и покрыт тестами через Check.h.

## Общие правила для проектов в репозитории

* **Язык:** C11 (GCC) под Linux и macOS.
* **Стиль:** Код форматируется через clang-format по стандарту Google Style.
* **Память:** Обязательная проверка на утечки (Valgrind / leaks).
* **Тесты:** Каждая библиотека собирается с юнит-тестами и отчетом о покрытии (gcov / lcov).
